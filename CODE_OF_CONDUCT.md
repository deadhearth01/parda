# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful and welcoming; no harassment, discrimination, personal attacks or publishing others' private information (which, for a privacy tool, includes pasting anyone's real personal data into issues).

## Enforcement

Report unacceptable behaviour privately to the maintainers through the contact listed on the repository's profile or via a private security advisory. Reports are handled confidentially. Maintainers follow the Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban), as described in section *Enforcement Guidelines* of the text linked above.

Attribution: Contributor Covenant, version 2.1, available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct.html>.
